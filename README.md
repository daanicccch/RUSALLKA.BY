# Эльбрус и Домбай - Горнолыжный Лендинг

Современный премиальный лендинг для горнолыжных туров на Эльбрус и Домбай от Rusallka.by.

## Технологии

- **React 18** - современная библиотека для UI
- **TypeScript** - типобезопасность и лучший DX
- **Vite** - молниеносная сборка и HMR
- **Tailwind CSS** - utility-first стилизация
- **Framer Motion** - плавные анимации
- **React Icons** - иконки

## Особенности

- Премиальный дизайн с glassmorphism эффектами
- Плавные анимации при скролле (Framer Motion)
- Адаптивная верстка (mobile-first подход)
- Градиенты и parallax эффекты
- Валидация форм с обработкой ошибок
- TypeScript для типобезопасности
- Переиспользуемые компоненты
- Оптимизированная структура проекта

## Структура проекта

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для production
npm run build

# Предпросмотр production сборки
npm run preview
```

## Секции лендинга

### Hero Section
- Полноэкранный баннер с фоном гор
- Анимированный заголовок и подзаголовок
- CTA кнопки
- Floating элементы (эмодзи гор, лыж, снежинок)
- Ключевые метрики (9 дней, 330 у.е., 2 курорта)

### Features Section
- 5 карточек с преимуществами тура
- Иконки и описания
- Анимация при скролле
- Glassmorphism эффекты

### Timeline Section
- Программа тура по дням (1-9 день)
- Вертикальный таймлайн с анимацией
- Иконки для каждого этапа
- Responsive дизайн

### Pricing Section
- Стоимость тура (330 у.е.)
- Список включенных услуг
- Сетка доступных дат (6 туров)
- Специальное предложение

### Routes Section
- 2 маршрута отправления
- Визуализация городов по пути
- Выделение основных точек
- Информация о транспорте

### Gallery
- Сетка из 6 изображений
- Hover эффекты с масштабированием
- Overlay с названиями
- Responsive layout

### Booking Form
- Валидация полей (имя, email, телефон)
- Обработка ошибок
- Состояние загрузки
- Сообщение об успешной отправке
- Иконки в инпутах

### Footer
- Социальные ссылки (Telegram, Viber, Instagram)
- Контактная информация
- Быстрые ссылки
- Copyright

## Цветовая схема

- **Primary Dark**: `#1a1a2e` - основной фон
- **Primary Darker**: `#16213e` - темнее фон
- **Accent Orange**: `#f16108` - акцентный цвет
- **Gradient**: `#ff6b6b` → `#ffa500` - градиенты

## Кастомные утилиты Tailwind

- `.glass-effect` - эффект матового стекла
- `.gradient-text` - градиентный текст
- `.gradient-bg` - градиентный фон
