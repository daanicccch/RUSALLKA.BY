# НАЧНИТЕ ОТСЮДА

Добро пожаловать в проект "Эльбрус и Домбай" - современный лендинг для горнолыжных туров.

## Быстрый старт (3 команды)

```bash
# 1. Установите зависимости
npm install

# 2. Запустите dev сервер
npm run dev

# 3. Откройте браузер
# http://localhost:5173
```

Готово. Проект запущен.

---

## Что дальше?

### Если вы разработчик

1. **Изучите структуру проекта:**
   - Откройте `FILES_STRUCTURE.md` - полная карта файлов
   - Изучите `src/App.tsx` - главный компонент
   - Посмотрите `src/components/sections/` - все секции

2. **Кастомизируйте под себя:**
   - Прочитайте `CUSTOMIZATION.md` - примеры кастомизации
   - Измените контакты в `src/utils/constants.ts`
   - Настройте цвета в `tailwind.config.js`

3. **Подготовьте к деплою:**
   - Следуйте `DEPLOYMENT.md` - полное руководство
   - Выберите платформу (Vercel, Netlify, GitHub Pages)
   - Настройте аналитику и домен

### Если вы клиент/владелец бизнеса

1. **Попробуйте демо:**
   - `npm run dev` → Откройте `http://localhost:5173`
   - Протестируйте на телефоне (адаптивность)
   - Заполните форму бронирования

2. **Что нужно изменить:**
   - Замените изображения на реальные фото туров
   - Обновите контакты (телефон, email, соцсети)
   - Проверьте даты туров и цены
   - Добавьте реальную интеграцию с Backend

3. **Развертывание:**
   - Передайте проект разработчику для деплоя
   - Или используйте Vercel (easiest) - см. `DEPLOYMENT.md`

### Если вы дизайнер

1. **Цветовая схема:**
   - `tailwind.config.js` - измените цвета
   - Доступны: primary, accent, градиенты

2. **Типография:**
   - `src/index.css` - смена шрифтов (Google Fonts)
   - По умолчанию: Inter

3. **Изображения:**
   - `src/components/sections/Hero.tsx` - главный баннер
   - `src/components/sections/Gallery.tsx` - фотогалерея

## FAQ

**Q: Сколько времени займет кастомизация?**
A: 1-2 часа для базовых изменений (тексты, цвета, контакты).

**Q: Нужен ли опыт в React?**
A: Для базовой кастомизации - нет. Для сложных изменений - желательно.

**Q: Как заменить изображения?**
A: Откройте файлы секций в `src/components/sections/` и замените URL.

**Q: Где изменить цены?**
A: `src/components/sections/Pricing.tsx` - массив `tourDates` и переменные.

**Q: Как добавить новую секцию?**
A: Создайте файл в `src/components/sections/`, импортируйте в `App.tsx`.

**Q: Какой хостинг выбрать?**
A: Vercel (рекомендуется), Netlify, или GitHub Pages - все бесплатные.

**Q: Как подключить форму к Backend?**
A: В `src/components/sections/Booking.tsx` замените `fetch` на ваш API.

**Q: Поддерживает ли SEO?**
A: Да, базовые мета-теги есть. Для продвинутого SEO добавьте JSON-LD.
